# SENSOR PRESENTATION + OLS V1 — завершено 2026-09-11

Продолжение существующего working tree. Ранее готовые изменения не откатывались. Checkpoints 1–5 завершены в объёме контрольных сценариев ниже. Ограничения проверки перечислены отдельно; покрытие всех устройств и возможных боевых ситуаций не заявляется.

## Уже было реализовано при восстановлении задачи

- Track presentation: feed-forward движения оценки и экспоненциальное сглаживание остатка, отдельно углов. Используются только reported/estimated данные, без подмены истинной позицией цели.
- Search radar routing: доступность Track определяется работающей сетью и покрытием, а не единственным владельцем/последним источником. Таймер coasting учитывает период обзора P-18/35D6/Pelikan; иначе редкий обзор ошибочно выглядел как потеря Track.
- Best sensor: среди доступных свежих игровых контактов учитываются quality, evidence, неопределённость позиции/скорости и возраст. Небольшое преимущество текущего источника уменьшает переключения. Offline-источники исключаются; смена источника не превращает разницу оценок в скачок скорости. Это существующий игровой fusion, без новых реальных алгоритмов наведения.
- AIM-120: legacy IMPACT совмещал 2D-спрайты участников; попадание такой позиции в 3D-буфер создавало визуальный скачок. Contact metadata и impact-aware adapter сохраняют точку существующего swept collision. Исправление относится к представлению, не к перенастройке guidance.
- OVERLAYS и отдельные коррекции осей PAC-3/Gerbera, локальных thermal anchors.

## Завершено в этом продолжении

- OLS/EO из карточки станции COMMAND. Один существующий Cesium Viewer сохраняется при переходах, заранее подгружает модели; скрытая сцена не ведёт второй simulation tick и останавливает render loop после прогрева.
- Фиксированная камера станции, ручной выбор объекта в кадре/списке видимых объектов, DAY / LOW-LIGHT / THERMAL. Небольшое зерно, виньетка и оптическая обработка дают менее стерильную картинку.
- Zoom 1–40×: колесо и вертикальная прокрутка двумя пальцами, также кнопки −/+. Нормализованы единицы wheel; FOV меняется плавно. Перетаскивание панорамирует и снимает сопровождение. ESC возвращает в сохранённый COMMAND view.
- Bracket и камера используют уже готовый buffered visual pose. Убрано устойчивое отставание камеры на большом zoom: движение цели учитывается непосредственно, сглаживается остаток захвата. Отдельной интерполяции физических объектов нет.
- После уничтожения OLS коротко удерживает место события, затем возвращается в FREE без автоматического выбора другой цели. Добавлены flash, тепловой след и остывание эффекта.
- Контактная visual metadata распространена на существующую FPV-коллизию. Удалённая в тот же simulation tick цель доигрывает общий buffered contact frame. Камера, модель, сопло и hotspot используют одну временную шкалу с ограничением по контакту.
- Контакт стал необратимым состоянием визуального жизненного цикла: сопло явно скрывается/удаляется и не восстанавливается после исчезновения модели. Этот дефект обнаружен и исправлен по реальной записи PAC-3.
- Устранён обнаруженный при hot reload доступ эффекта к ещё не готовому Viewer.

## Границы завершённой приёмки

- Незавершённых пунктов реализации этого milestone в контрольных сценариях не осталось. Завершающий проход потребовал только расширения dev fixture для воспроизводимого сетевого FPV; игровая реализация не переписывалась.
- Каждый search radar → FPV проверен отдельно автоматическим checkFpvSensorPresentation; в браузере FPV проверен с тремя одновременно работающими search radars. Полная комбинаторная матрица радаров/моделей не выполнялась.
- Физический жест пальцами на MacBook не выполнялся, проверены wheel events и эквивалентность малых delta.
- Не проверены все модели, ракурсы, размеры окна и длительные игровые сессии. Точное совпадение поведения со всеми тремя присланными видео не заявляется.
